## Hệ thống Agentic RAG

Xây dựng hệ thống RAG nhiều bước với LangGraph/LangChain, hỗ trợ multi-turn conversation, query rewriting và guardrails nhằm giảm hallucination và tăng độ ổn định của AI Agent.

## AI-Driven Inventory Manager

Thiết kế hệ thống AI Agent tích hợp với backend .NET thông qua Model Context Protocol (MCP), hỗ trợ truy vấn và quản lý kho bằng ngôn ngữ tự nhiên.

## AGENTIC STOCK FORECASTING SYSTEM

Xây dựng hệ thống nghiên cứu định lượng tích hợp AI Agent với LangGraph và LightGBM Quantile Regression, hỗ trợ probabilistic forecasting, monitoring drift/regime/risk và cơ chế self-correction cho mô hình.

## Phát hiện và phân vùng vùng da ung thư bằng học sâu

Huấn luyện và benchmark nhiều mô hình Computer Vision trên gần 17.000 ảnh y tế, đạt 76.2% mAP@50 và 84.3% recall.

## Phân loại tin giả với mô hình lai BERT-XLNet

Xây dựng mô hình hybrid NLP xử lý hơn 78.000 bài báo tiếng Anh, đạt 90.42% accuracy và 91.63% recall.

## Phân tích chỉ số sức khỏe bệnh tiểu đường

Thực hiện EDA, statistical testing và huấn luyện mô hình học máy trên hơn 250.000 bản ghi y tế, đạt kết quả tốt với XGBoost.
